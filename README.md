# ✦ Content OS — Marketing System

ระบบหลังบ้านการตลาดออนไลน์สำหรับร้านค้าและแบรนด์ ใช้ได้หลายแบรนด์ในโปรแกรมเดียว ทำงานในเครื่องคุณทั้งหมด (Windows) ไม่ต้องสมัครบริการไหน และใช้ร่วมกับ **Claude (Cowork)** ให้ช่วยวิเคราะห์ อัปเดตตัวเลข และเขียนคอนเทนต์ได้

สร้างด้วยการคุยกับ AI (Claude) โดยไม่ต้องเขียนโค้ดเอง

**▶ ลองเล่นเดโม:** https://wannisakarn.github.io/content-os/ (โหมดทดลอง ข้อมูลเก็บในเบราว์เซอร์)

## ติดตั้ง (Windows 10/11)

1. กดปุ่มสีเขียว **Code → Download ZIP** แล้วแตกไฟล์ไว้ที่ไหนก็ได้
2. ดับเบิลคลิก **`Create Desktop Icon.bat`** (ครั้งเดียว) จะมีไอคอน **Content OS** ขึ้นที่ Desktop
3. ดับเบิลคลิกไอคอนเพื่อเปิดใช้งาน แล้วกด **เพิ่มแบรนด์ / ธุรกิจ**

ไม่ต้องลงโปรแกรมเพิ่ม เพราะใช้ PowerShell และ Microsoft Edge ที่มากับ Windows อยู่แล้ว ถ้า Windows ขึ้นเตือนตอนเปิดไฟล์ ให้กด "More info → Run anyway"

## ทำงานยังไง

```
ไอคอน Desktop → start.vbs → server/server.ps1 (http://localhost:8787 เฉพาะเครื่องนี้)
                                   ├─ app/                  หน้าเว็บแอป
                                   └─ data/brands/<id>/data.json   ข้อมูลแต่ละแบรนด์
```

- แก้อะไรในแอป ระบบจะบันทึกลงไฟล์ให้ทันที และสำรองไว้ที่ `data/backups/` ส่วนแบรนด์ที่ลบจะย้ายไปไว้ที่ `data/archive/` (กู้คืนได้)
- ตัวเซิร์ฟเวอร์ปิดตัวเองเมื่อไม่ได้ใช้งานครบ 30 นาที
- ข้อมูลไม่ออกจากเครื่องคุณ และไม่มีการส่งข้อมูลไปที่ไหน

## ใช้กับ Claude

1. ใน Claude desktop (Cowork) กด **Add folder** แล้วเลือกโฟลเดอร์โปรแกรมนี้
2. ในแอปเปิดเมนู **สั่งงาน Claude** แล้วคัดลอกคำสั่งไปวาง เช่น รายงานเช้า ส่องคู่แข่ง หาเทรนด์ วางแผนคอนเทนต์ 2 สัปดาห์ หรือวิเคราะห์โฆษณา
3. ถ้าต้องการให้ทำอัตโนมัติ พิมพ์ต่อท้ายว่า *"ตั้งเป็น scheduled task ทุกวัน 6:00"*

Claude จะแก้ไฟล์ `data.json` ตามโครงสร้างที่เขียนไว้ใน [`คู่มือสำหรับ Claude.md`](คู่มือสำหรับ%20Claude.md) จากนั้นแอปจะรีเฟรชเองภายใน 15 วินาที

## หมายเหตุ

- แบรนด์ **Mali Skin** และ **บ้านกาแฟ Roastery** เป็นข้อมูลสมมติไว้ให้ดูเป็นตัวอย่าง ลบได้ในหน้า Context Memory
- เมนูตั้งเวลาโพสต์ใช้จัดคิวและเตือนเท่านั้น การโพสต์จริงต้องตั้งเวลาใน Meta Business Suite หรือ TikTok Studio
- ข้อมูลจริงของคุณใน `data/brands/` จะไม่ถูกอัปโหลดขึ้น GitHub (ตั้งค่าไว้ใน `.gitignore`)
